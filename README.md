# Vedic Nature — Luxury Botanical Oils Homepage (v3, Maison edition)

Next.js 14 (App Router) + Tailwind CSS. Restyled as an international perfume house.

## Design
Minimal luxury. Cormorant (headlines) + Jost (text). Colour used with restraint:
- Deep Emerald `#123D32` · Obsidian `#0A241D`
- Silk Alabaster `#F6F2EA` · Champagne `#ECE5D8`
- Gold `#B89A5E` (hairlines and small accents only)

## Motion & interaction
Smooth scrolling (Lenis), a brand intro once per session, custom cursor on products,
parallax photography, masked headline reveals, scroll-filled manifesto, hide-on-scroll header.
Hero image: put your banner at `public/images/vedic.png`.

## Quick start
```bash
npm install
npm run dev
```
Open http://localhost:3000
